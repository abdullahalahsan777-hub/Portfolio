## What's Included in Version v1.0.0

### 1. Multi-Theme Core Architecture
- Five specialized frontend themes: Developer, App Developer, App Software Developer, UI/UX Designer, and Graphic Designer.

### 2. Website Group Studio Editor
- Dynamic admin content manager for Home, About, Contact, Services, Projects, Skills, Resume, Blog, FAQs, Pricing, and Testimonials.

### 3. Authentication & Access Control
- Secure login, user registration, password recovery, and role management.

### 4. Media & Settings Management
- WebP image processing pipeline, brand logo customization, and social coordinates.

## Server Port Configuration

Configured exclusively via `SERVER_PORT` in your `.env` file:

```env
SERVER_PORT=8044
APP_URL=http://127.0.0.1:8044
```

## How to Update to Latest Version (v1.3.0)

1. Open your Admin Panel at `/admin/versions`.
2. Click **Update to v1.3.0** on the version card or top synchronization banner.
3. Review the **"What's New in this Update"** popup modal.
4. Click **Confirm & Update Now** to complete the automatic update.
