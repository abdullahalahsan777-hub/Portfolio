## What's Included in Version v1.1.0

### 1. Full 4xx & 5xx Custom Error Suite
- Beautiful branded error pages with responsive SVGs for 400, 401, 403, 404, 405, 408, 410, 429, 500, 502, 503, and 504.

### 2. Interactive Error Showcase Hub
- Preview hub (`/errors`) allowing administrators to audit all HTTP error states and visual presentations.

### 3. Structured Exception Reporting
- Global exception report handling logging route, action, method, URL, user identity, and IP address.

## Server Port Configuration

Configured exclusively via `SERVER_PORT` in your `.env` file:

```env

APP_URL=http://127.0.0.1:8044
```
